== Mobile NixOS compliance audit

The Mobile NixOS kernel assertions expect a few options that currently deviate from the recommended defaults:

* `CONFIG_UEVENT_HELPER` is enabled with an empty helper path (`""`), while Mobile NixOS requires the helper to be disabled entirely to avoid userspace hotplug fallbacks.【F:devices/families/sdm660-mainline/kernel/config.aarch64†L1564-L1567】
* `CONFIG_FW_LOADER_USER_HELPER` remains enabled even though the platform should rely on kernel-side firmware loading; Mobile NixOS marks this option as forbidden.【F:devices/families/sdm660-mainline/kernel/config.aarch64†L1575-L1585】
* `CONFIG_FRAMEBUFFER_CONSOLE_DEFERRED_TAKEOVER` is set, whereas the Mobile NixOS defaults request it to stay disabled on modern kernels.【F:devices/families/sdm660-mainline/kernel/config.aarch64†L3966-L3970】

Addressing the three items above (disabling the userspace uevent helper, disabling the firmware loader helper, and turning off deferred fbcon takeover) will bring the configuration back in line with the Mobile NixOS assertions.
